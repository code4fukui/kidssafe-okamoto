# 越前市岡本地区向け KidsSafe

越前市岡本地区向けのコミュニティマップで、安全・文化・観光情報を可視化します。データはシンプルなCSVファイルを用いてコミュニティによって管理されます。

## デモ

https://code4fukui.github.io/kidssafe-okamoto/

## 特徴

- **インタラクティブマップ:** 以下のコミュニティデータを可視化します:
  - **安全スポット:** AED、こども110番の家、防犯カメラ、パトロールルート。
  - **危険箇所情報:** 交通事故の発生場所。
  - **文化・観光スポット:** 越前和紙の工房や地域の名所。
- **コミュニティ主体の管理:** データはCSVファイルで簡単に更新でき、Excel、Numbers、Googleスプレッドシートなどのツールで編集可能です。
- **カスタマイズ可能:** データの種類に応じたカスタムマップアイコンに対応しています。
- **オープンソース:** [Code for FUKUIのKidsSafeプロジェクト](https://github.com/code4fukui/kidssafe/)をベースに構築されています。

## マップの使い方

### ホーム画面への追加
スマートフォンでこのサイトをホーム画面に追加すると、アプリのように素早くアクセスできるようになります。

### サイト言語の変更
マップのインターフェース言語は、様々なユーザーに合わせて切り替えることができます。

## データ管理

すべてのマップデータはこのリポジトリ内のCSVファイルとして保存されており、コミュニティで簡単に更新できるようになっています。

### 1. 既存データの更新

1. 変更したいデータファイル（例: [aed.csv](aed.csv)）を開きます。
2. ファイルをパソコンにダウンロードします。
3. 表計算ソフト（スプレッドシートアプリ）でファイルを開き、編集します。
4. 編集したファイルをリポジトリのルートディレクトリにアップロードして上書きします。マップは自動的に更新されます。

### 2. 新しいデータカテゴリの追加

1. [template.csv](template.csv) ファイルをダウンロードします。
2. 1行につき1か所の新しいデータを追加します。
3. わかりやすいファイル名（例: `parks.csv`）を付け、CSV UTF-8形式で保存します。
4. [index.csv](index.csv) をダウンロードして編集し、新しいカテゴリを定義する行（例: `Parks,parks.csv,park_icon.png`）を追加します。
5. 新しいデータのCSVファイルと、更新した `index.csv` の両方をルートディレクトリにアップロードします。

### 3. カスタムアイコンの追加

1. 100x100ピクセル程度のPNG画像を準備し、わかりやすい英語のファイル名（例: `park_icon.png`）を付けます。
2. 画像を [icon](icon) フォルダにアップロードします。
3. `index.csv` やその他のデータファイル内で新しいアイコンのファイル名を指定すると、マップ上で使用されるようになります。
